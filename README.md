# E-Commerce Sales Data Analysis Using Python

## Project Overview

This project analyzes an e-commerce sales dataset using Python to understand sales performance, profitability, product categories, and regional performance.

## Objectives

* Calculate total sales, profit, and unique orders.
* Identify the highest-selling product category.
* Analyze sales across different regions.
* Study monthly sales trends.
* Identify the top 10 products by sales.
* Generate useful business insights.

## Tools and Technologies

* Python
* Pandas
* Matplotlib
* Kaggle Notebook
* GitHub

## Project Analysis

1. Overall Sales and Profit Analysis
2. Sales by Product Category
3. Sales by Region
4. Monthly Sales Trend
5. Top 10 Products by Sales
6. Business Insights

## Conclusion

This project demonstrates how Python and data visualization can help analyze business data and identify useful insights for better decision-making.
